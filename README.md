## 📋 Deskripsi
Sistem AI untuk optimasi formulasi ransum ternak menggunakan Linear Programming dan machine learning.

## ✨ Fitur Utama
- ✅ AI Optimasi Formula Pakan
- ✅ Database 16+ Bahan Ternak
- ✅ Grafik Nutrisi Real-time
- ✅ Login Admin
- ✅ Penyimpanan Formula (LocalStorage)
- ✅ Export PDF
- ✅ Mobile Friendly
- ✅ Dukungan 6 Jenis Ternak

## 🚀 Cara Menggunakan
1. Buka website: [https://anggalintang14-lab.github.io/Repository-name-gerotak-farm-pro/](https://anggalintang14-lab.github.io/Repository-name-gerotak-farm-pro/)
2. Login dengan:
   - Username: `admin`
   - Password: `1234`
3. Pilih jenis ternak dan nutrisi target
4. Klik "AI Optimasi Formula"
5. Lihat hasil, simpan, atau export sebagai PDF
